## Introduction

Ugarit Fortify is a frontend agnostic authentication backend for Ugarit. Fortify powers the registration, authentication, and two-factor authentication features of [Ugarit Starter Kits](https://ugarit.com/starter-kits).

## Official Documentation

Documentation for Fortify can be found on the [Ugarit website](https://ugarit.com/docs/fortify).
